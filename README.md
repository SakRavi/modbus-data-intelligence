# MODBUS-DATA-INTELLIGENCE (MDI)

Local Python platform for acquiring, processing, and monitoring energy data
through Modbus and Victron Cerbo GX.

Designed for local energy monitoring, IoT integration, technical alerts,
data analysis, and future machine-learning applications.
